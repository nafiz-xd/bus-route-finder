# 🚌 Dhaka Bus Route Finder

Find which Dhaka city buses go from one place to another — with direction, stop sequence and an estimated fare.

## 🌐 Live Demo

**https://nafiz-xd.github.io/bus-route-finder/**

## ✨ Features

- **16 real Dhaka bus services** built in — Raida, Victor Paribahan, Akash, Shadhin, Midline, Trans Silva, Labbaik, Mirpur Metro, BRTC, Asmani, Ramjan, Turag, Projapoti, Alif, Bhuiyan and Safa Marwa — each with its full ordered stop list (10–14 stops)
- **From / To search** with autocomplete over every stop in the city, plus a swap button
- **Smart results** — every bus passing both stops, sorted by fewest stops, showing travel direction, stops in between, distance and the exact stop sequence for your journey
- **Estimated fare** — distance approximated from the number of stops (~1.1 km per stop) at the standard city rate of ৳2.45/km, with a ৳10 minimum fare
- **Bus directory** — filter all buses by name and click any bus to see its complete route as a visual stop timeline
- Helpful fallback message with hub suggestions (Farmgate, Gulistan, Motijheel…) when no direct bus exists
- Fully responsive, single-file app — no build step, no dependencies

## 🛠️ Tech

- HTML5, CSS3, Vanilla JavaScript (single `index.html`)
- Hosted on GitHub Pages
